# More singly linked lists

C project on more singly linked list manipulation.

## Files

| File | Description |
| ---- | ----------- |
| `lists.h` | Header with the `listint_t` structure and prototypes. |
| `8-sum_listint.c` | Returns the sum of all the data (`n`) of a list. |
| `9-insert_nodeint.c` | Inserts a new node at a given position. |
| `10-delete_nodeint.c` | Deletes the node at a given index. |
| `100-reverse_listint.c` | Reverses a list (1 loop, 2 vars, no malloc/free/arrays). |
| `101-print_listint_safe.c` | Prints a list, safe for lists with loops. |
| `102-free_listint_safe.c` | Frees a list, safe for lists with loops. |
| `103-find_loop.c` | Finds the loop in a linked list (Floyd's algorithm). |

## Requirements

- Ubuntu 20.04 LTS
- Compiled with `gcc -Wall -pedantic -Werror -Wextra -std=gnu89`
